# Hookmaster

A small Godot 4 platformer prototype with movement, combat, hookshot traversal, and a boss-chase scene.

## Run

Open `project.godot` in Godot and press **F6** or **F5**.

## Controls

- Move: Left/Right arrow keys
- Jump: Up arrow key
- Dash: Shift
- Attack: F
- Hookshot: E
- Pogo: Down arrow + F while airborne
- Reset scene: R

## Project layout

- `scenes/` — Godot scenes
- `scripts/` — gameplay code
- `assets/` — game-specific art, audio, and licenses
